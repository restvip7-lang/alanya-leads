# Google Таблица для Асель

Новые заявки из парсера сами появляются в таблице. Асель ставит статус из списка
(Новая, Не дозвонилась, Написала, В работе, Показ назначен, Сделка, Не актуально),
пишет комментарий («позвонила, перезвонить в пятницу») и дату следующего шага.
Строка красится по статусу, есть фильтры. Работает и с телефона в приложении Google Таблицы.

## Подключение (10 минут, один раз)
1. Создайте новую Google Таблицу, назовите, например, «Заявки Алания».
2. Меню **Расширения → Apps Script**. Удалите то, что там есть, вставьте содержимое `Code.gs`.
3. В строке `const SECRET = 'ПОМЕНЯЙТЕ-МЕНЯ';` впишите свой пароль (любой набор букв и цифр). Сохраните.
4. Сверху выберите функцию **setup** и нажмите **Выполнить**. Google попросит доступ к таблице: разрешите.
   На листе «Заявки» появятся колонки, список статусов и цвета.
5. **Начать развёртывание → Новое развёртывание → Веб-приложение**.
   «Выполнять от имени»: **меня**, «У кого есть доступ»: **Все**. Нажмите «Начать развёртывание»,
   скопируйте ссылку, которая заканчивается на `/exec`.
6. В `config.ini` парсера:
   ```
   webhook_url = https://script.google.com/macros/s/.../exec
   webhook_secret = тот же пароль, что в шаге 3
   ```
7. Дайте Асель доступ к таблице (кнопка «Настройки доступа», роль «Редактор»).

Проверка: откройте ссылку `/exec` в браузере, должно быть «приём работает».
Без пароля таблица ничего не примет. Повторные заявки (тот же пост) не дублируются.
