# Парсер заявок на покупку недвижимости, Алания

Читает Telegram-чаты, в которых вы состоите, и отбирает сообщения, где человек хочет **купить**
квартиру/виллу в Алании (RU / EN / TR). Объявления «продам», «сдам», «сниму» отсекаются.
Для каждой заявки сохраняет: дату, чат, автора, бюджет и валюту, тип (1+1, 2+1, вилла…),
район, контакты из текста, сам текст и ссылку на сообщение.

## Установка
```bash
pip install -r requirements.txt
cp config.example.ini config.ini
```
1. Зайдите на https://my.telegram.org → API development tools, создайте приложение, вставьте `api_id` и `api_hash` в `config.ini`.
2. Впишите в `config.ini` список чатов (по одному на строку).

## Запуск
```bash
python parser.py           # за последние N дней из config.ini
python parser.py --days 30 # за 30 дней
```
При первом запуске Telegram пришлёт код входа. Сессия сохранится в `alanya_session.session`
(этот файл и `config.ini` не попадают в git, это ваш доступ к аккаунту).

Результат пишется в `data/leads.csv` (дописывается, дубли пропускаются). Для Excel укажите
`file = leads.xlsx`.

## Запуск в облаке (GitHub Actions, 07:53, 12:53, 16:53 по Турции)
Парсер сам запускается на серверах GitHub три раза в день (и в выходные), отправляет новые заявки
в кабинет Асель, а потом бот сайта присылает админам сообщение «Новых заявок: N».
Компьютер для этого не нужен. Чаты берутся из `config.example.ini` (секция `[sources]`).

Настройка один раз:
1. На своём компьютере в папке парсера: `python login.py`. Введите `api_id`, `api_hash`, телефон и код
   из Telegram. Скрипт напечатает длинную строку сессии. **Это ключ от вашего Telegram:** не пересылайте
   её никому и никуда, кроме шага 2.
2. GitHub → репозиторий → Settings → Secrets and variables → Actions → New repository secret.
   Добавьте пять секретов:
   - `TG_API_ID`, `TG_API_HASH`: с my.telegram.org;
   - `TG_SESSION`: строка из шага 1;
   - `WEBHOOK_URL`: `https://assel-chi.vercel.app/api/leads/`;
   - `WEBHOOK_SECRET`: тот же пароль, что `LEADS_SECRET` в Vercel.
3. Вкладка Actions → «Сбор заявок» → Run workflow: проверочный запуск. Дальше он идёт сам.

Каждый запуск смотрит последние 16 часов (утром захватывает всю ночь), повторы кабинет отбрасывает сам.
GitHub иногда запускает по расписанию с опозданием до 10–20 минут, это нормально.
Если запуск красный, откройте его в Actions: там написано, что не так. Если GitHub пишет, что
расписание отключено из-за неактивности репозитория (бывает через 60 дней без коммитов), нажмите
там же «Enable workflow».

## Facebook-группы
Автоматически читать Facebook-группы нельзя: Facebook запрещает автоматический сбор данных
и блокирует за это аккаунты, а официального API для групп больше нет. Поэтому посты из групп
копируются вручную в текстовый файл (между постами строка `---`, ссылку на пост можно
вставить прямо в текст), а дальше их обрабатывает тот же фильтр:
```bash
python import_posts.py facebook.txt --group "Русские в Алании"
```
Заявки попадают в тот же `data/leads.csv` (источник `facebook`), повторы пропускаются.

## Кабинет Асель
Заявки сами попадают в кабинет на сайте Асель (`/cabinet/`, репозиторий `assel`). Она входит
через бота командой `/leads`, ставит статус, пишет комментарий и дату следующего шага.
В `config.ini`: `webhook_url = https://assel-chi.vercel.app/api/leads/`, `webhook_secret` равен
`LEADS_SECRET` из настроек Vercel. Запасной вариант без сайта: Google Таблица, см.
[google_sheet/README.md](google_sheet/README.md).

Технически это webhook: если в `config.ini` заполнены `webhook_url` и `webhook_secret`, каждая
новая заявка отправляется POST-запросом с JSON (пароль в поле `secret` и в заголовке `X-Leads-Secret`). Поля: `date`, `source`,
`chat`, `author`, `author_profile`, `budget`, `currency`, `budget_raw`, `property_type`,
`districts`, `contacts`, `text`, `link`, `id`.

## Настройка фильтра
Ключевые слова, районы и типы объектов лежат в `filters.py`. Проверка: `python test_filters.py`.

## Важно
- Собираются только сообщения из чатов, где вы участник, и только то, что автор сам опубликовал.
- Храните `data/leads.csv` в **приватном** репозитории: там имена и контакты людей.


## Квартиры от собственников (owners.py)

Отдельный парсер: в тех же чатах ищет объявления о продаже квартир от собственников (не агентств) в Алании.
Агентства отсеиваются по словам в тексте («агентство», «рассрочка», «ID объекта»…), по имени автора («Realty», «Недвижимость»…),
по постам от имени канала и по числу разных квартир от одного автора. Виллы, дома, участки и аренда не берутся.

Каждая квартира уходит в кабинет на `listings_url` (страница `/cabinet/listings/`: «Сегодня» и «Все», по районам и планировкам),
после запуска бот присылает одно сообщение-сводку в общий чат. Чтобы подключить чат: добавьте в группу бота @asselweb_bot и отправьте там `/listings`.

Запускается в GitHub Actions сразу после заявок покупателей, той же сессией Telegram. Проверить у себя без отправки:

    python owners.py --days 3 --dry
